### Learning Go language

## Installation

1. Download Go Lang package from Go website.
2. Install it.
3. Install the Go Lang extension feature in VS Code.
4. Ready to Code.

## Features

#### 1. Compiled

#### 2. No need of JVM or other

#### 3. Executables are different for OS

#### 4. Case Sensitive

### Is it Object Oriented ?

#### Yes or No

1.  Instead of classes and objects we have structs.
2.  Also we don't have any overloading or overriding here.

## Lexer

1. Lexer provides all packages.
2. The formal uses semicolon and lexer checks does the code follows the grammar rules.
3. It doesn't solve the problem for logical issues, but if you not follow grammar , at the time of running the code lexer comes into picture.
   **_Eg:- If you forgot to add semicolon at the end , then while running the code lexer adds them._**

## Writing our first code

1. Create a folder . Eg: hello
2. Create a file with extension .go . Eg: main.go
3. After these steps open the terminal in VS code type **_go mod init <module_name>_** . Eg: **go mod init hello**
   1. It is used to create the module named hello

## Commands

1. **go help** - It gives you commands you can use with go.
2. **go help <command_name>** - It gives you the details of specific command that you want to know.
3. **go mod init <module_name>** - It creates a module.
4. **go run <file_name>** - It runs the file of .go .
